`scrcpy-server` is the device-side server of [scrcpy](https://github.com/Genymobile/scrcpy) v3.3.3
(Copyright Genymobile and Romain Vimont, Apache License 2.0), unmodified. OpenTV Companion's "TV on Mac" window
runs it on the TV over adb and speaks its protocol. Its version must match `ScrcpySession.serverVersion`.
