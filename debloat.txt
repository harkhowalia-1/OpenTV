# Phone/Mac remote: the launcher's HomeKeyService runs a small web server on port 8800 (http://192.168.1.50:8800).
#   Devices pair once with a 4-digit code shown on the TV. To forget all paired devices:
#   adb shell am force-stop com.gathin.tvhome; adb shell run-as com.gathin.tvhome rm shared_prefs/remote.xml
#   (then re-enable the accessibility service line above).

# Bonjour: the remote server is advertised as "_tvremote._tcp" ("<TV name> Remote", TXT name=<TV name>), so the
#   native iPhone and Mac apps (tv-remote-apps/) find the TV without its address.
# Apple Home: HomeKeyService also runs a HomeKit television accessory (HAP-Java) on port 9123, advertised as
#   "_hap._tcp". Add it from the Home app with the QR code under Settings > Apple Home (or Control Center >
#   Apple Home). It then also appears in the iPhone's built-in Apple TV Remote in Control Center.
#   To forget every Home it was added to: Settings > Apple Home > Remove from Apple Home, or
#   adb shell am force-stop com.gathin.tvhome; adb shell run-as com.gathin.tvhome rm shared_prefs/homekit.xml
#   (then re-enable the accessibility service line above).
